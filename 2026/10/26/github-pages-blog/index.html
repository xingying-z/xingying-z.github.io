用 GitHub Pages 免费托管博客

发表于2026-10-26|更新于2026-10-26|教程
|浏览量:

静态博客最大的好处是：没有服务器要维护，也没有数据库要备份。生成一堆 HTML，扔给 CDN，就完事了。

三种常见托管方式

方案 成本 自定义域名 构建
GitHub Pages 免费 支持 本地构建后推送
Cloudflare Pages 免费 支持 可自动构建
Vercel / Netlify 免费额度 支持 可自动构建

仓库命名很关键

  • 用户站：仓库叫 <用户名>.github.io，访问地址就是 https://<用户名>.github.io
  • 项目站：仓库叫任意名字，访问地址多一层 /<仓库名>/

选错的话，CSS 和图片会因为路径不对而全部 404。项目站需要额外改 root：

发布流程

hexo deploy 会把 public/ 推到仓库的 main 分支，然后 GitHub 自动发布，通常一两分钟生效。

几个容易踩的坑

  1. 国内访问 *.github.io 可能不稳定，可以考虑 Cloudflare Pages 或自有域名 + CDN。
  2. 首次部署后是 404，多半是 Pages 的 Source 没选对，或者构建还没跑完。
  3. 图片别用外链图床，图床挂了文章就花了，放进 source/img/ 最稳。
